Task 4: SVM Classification Models

Overview

This document summarizes the methods and findings for Task 4, which involved developing Support Vector Machine (SVM) models for binary and multi-class classification of web page claims data.

Text Preprocessing

The preprocessing pipeline consisted of the following steps:

  1. HTML Parsing: Extracted text from paragraph and header tags (p, h1-h6) using rvest
  2. Text Cleaning:
    • Removed URLs and email addresses
    • Removed punctuation, digits, and special symbols
    • Converted to lowercase
    • Normalized whitespace
  3. Tokenization: Split text into individual word tokens using tidytext::unnest_tokens
  4. Stopword Removal: Filtered out common English stopwords
  5. Lemmatization: Reduced words to their base forms using textstem::lemmatize_words
  6. Feature Selection: Selected top 1000 most frequent terms from training data
  7. TF-IDF Vectorization: Calculated term frequency-inverse document frequency scores
  8. Z-score Standardization: Applied z-score normalization to all features using training set parameters

Predictive Models

Binary Classification Model

  • Algorithm: Support Vector Machine with linear kernel
  • Implementation: e1071::svm
  • Hyperparameters: Cost = 1
  • Target Variable: bclass (Relevant claim content vs. N/A: No relevant content)
  • Features: 1000 TF-IDF features (z-score normalized)

Multi-class Classification Model

  • Algorithm: Support Vector Machine with linear kernel
  • Implementation: e1071::svm (one-vs-one strategy)
  • Hyperparameters: Cost = 1
  • Target Variable: mclass (multiple claim categories)
  • Features: 1000 TF-IDF features (z-score normalized)

Model Performance

Model performance was estimated using an 80/20 train-validation split on the training data:

Model Estimated Accuracy
Binary Classification 69.7%
Multi-class Classification 68.0%

Key Findings

  1. Binary Model Performance: The binary SVM model achieved approximately 70% accuracy in distinguishing between pages with relevant claim content and those without, representing a substantial improvement over the baseline logistic PCR model (61.6% from Task 1).

  2. Multi-class Model Performance: The multi-class model achieved 68% accuracy across multiple claim categories, demonstrating reasonable performance on this more challenging classification task.

  3. Feature Engineering: The combination of TF-IDF vectorization with z-score standardization provided effective feature representation for the SVM models.

  4. Model Simplicity: Linear kernel SVMs with default hyperparameters provided competitive performance without extensive tuning, suggesting that the feature engineering was effective.
